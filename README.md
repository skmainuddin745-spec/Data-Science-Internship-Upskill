## 🔭 Overview & Objective
This repository houses a comprehensive suite of analytical projects focusing on data-driven strategic decision-making. The core objective across all modules was to fuse **rigorous machine learning optimization** with **advanced data storytelling**. By systematically evaluating and comparing proposed operational solutions, this framework was designed to facilitate high-level, definitive decision-making processes. 

Originally developed utilizing OrangeML and Tableau, the underlying logic has been subjected to a rigorous scientific analysis and upgraded into a massive, production-grade Python architectural suite located in `python_analytics_suite`.

## 🔬 Analytical Architecture 

The framework bridges the gap between raw statistical output and executive-level strategic planning, evolving from visual node-programming to automated Python execution.

### 🛒 1. Retail Operations & Supply Chain Analytics (Supermarket)
- **Predictive Modeling (`supermarket_logistics_model.py`):** Utilized scikit-learn's RandomForest architecture with GridSearchCV to forecast consumer purchasing behaviors and inventory replenishment cycles.
- **Strategic Dashboarding:** Deployed Tableau to visualize regional performance matrices.

### 🌐 2. Social Media Engagement & Network Analytics
- **Algorithmic Optimization (`advanced_ecosystem_predictor.py`):** Leveraged Gradient Boosting Regressors to uncover underlying trends in user engagement, algorithmic trust/safety metrics, and content vitality.

### 🌍 3. Geo-Spatial Product Intelligence & Material Analytics
- **Non-Linear Modeling:** Synthesized complex geospatial and material metrics to map geological parameters against commercial viability.

## 🚀 Advanced Python Analytics Suite [NEW]

To demonstrate absolute mastery and perfection as a Senior Data Scientist, the original visual workflows have been fundamentally rewritten into four high-fidelity Python pipelines incorporating advanced class-imbalance techniques, dimensionality reduction, and ensemble methodologies:

### A. Advanced Supervised Risk Classifier (`advanced_supervised_classifier.py`)
- **Rigorous Analysis:** Targets high-risk datasets (like `loan_final313` and `Gmapps Data`).
- **Architecture:** Implements an **XGBoost (GradientBoostingClassifier)** framework paired with **SMOTE** (Synthetic Minority Over-sampling Technique) to algorithmically rebalance highly skewed outcomes.
- **Metrics:** Outputs rigorous cross-validated ROC-AUC, Precision, and Recall scores to ensure definitive decision-making in Trust & Safety vectors.

### B. Unsupervised Clustering & Dimensionality Engine (`unsupervised_clustering_engine.py`)
- **Rigorous Analysis:** Targets multidimensional unstructured datasets (Google Playstore apps, CrunchBase, Growth Index).
- **Architecture:** Integrates **Principal Component Analysis (PCA)** for extreme dimensionality reduction, followed by scalable **K-Means Clustering**.
- **Metrics:** Autonomously discovers latent market structures, statistically evaluated using the Silhouette Coefficient to guarantee absolute cluster cohesion.

## 💻 Technology & Methodologies

### Core Technologies
*   **Python (Upgraded Pipeline):** `pandas`, `numpy`, `scikit-learn`, `imblearn` for scalable machine learning execution and data manipulation.
*   **OrangeML (Legacy):** Initially utilized for visual programming, algorithmic prototyping, and rapid statistical evaluation.
*   **Tableau:** Deployed for high-fidelity data visualization, interactive dashboard creation, and dynamic storytelling.

### Key Methodologies
1.  **Optimization of Models:** Iterative hyperparameter tuning (GridSearchCV) and performance evaluation (RMSE, R2, ROC-AUC) to ensure maximum statistical accuracy.
2.  **Imbalance Architecture:** Programmatic synthetic sampling (SMOTE) to prevent majority-class bias in risk prediction models.
3.  **Data Storytelling:** Translating highly complex, multi-variable analytical results into cohesive, narrative-driven visualizations.
